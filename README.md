# RBI_Complaint_Analytics
# Customer Complaint Analytics & Policy Insights Platform

## Overview
An end-to-end complaint analytics platform developed using Python, SQL, and Power BI to analyze large-scale consumer financial complaint data and generate policy-oriented insights.

## Technologies Used
- Python
- Pandas
- NumPy
- SQLite
- SQL
- Power BI

## Dataset
Consumer Financial Protection Bureau (CFPB) Consumer Complaint Database

## Features
- Complaint trend analysis
- Institution-wise complaint monitoring
- State-wise complaint analysis
- Resolution status tracking
- Automated data cleaning and transformation
- SQL-based reporting
- Interactive Power BI dashboard

## Key Insights
- Credit card complaints constitute the largest complaint category.
- Complaint volumes are concentrated among a small number of institutions.
- California, Florida, and Texas account for the highest complaint volumes.
- Response rate exceeds 96%.
